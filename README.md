# MovieFlix

Sistema Web de locadora de filmes. O cliente faz o aluguel da produção desejada, recebe a permissão de assistir determinada obra até certo período de tempo. Além da possibilidade da avalição de diversos filmes.

## Funcionalidades

- Cadastro e login de diversos usuários
- Catálogo diversos e variados de filmes
- Aluguel de filmes prático
- Sistema de avaliações das obras
- Envio de críticas, elogios ou dúvidas
- Painel de perfil para registro de suas atividades no sistema
- Painel administrativo

## Tecnologias

- PHP 8.2
- MySQL 8
- HTML, CSS e JavaScript
- XAMPP (ambiente local)

## Como rodar

1. Instale o XAMPP e ligue Apache e MySQL.
2. Copie a pasta `MovieFlix` para `C:\xampp\htdocs`.
3. No phpMyAdmin, importe `database/movieflix.sql`.
4. Acesse http://localhost/movieflix
Passos detalhados em `docs/instalacao.md`.
