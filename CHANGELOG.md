# Changelog

Todas as mudanças importantes do MovieFlix ficam registradas aqui, da versão mais nova para a mais antiga.

O número da versão segue o padrão MAIOR.MENOR.CORREÇÃO. Cada versão representa uma etapa importante da evolução do projeto.

- Finalização e testes das avaliações.
- Finalização e testes dos cupons de desconto.
- Aprimoramento da integração entre as páginas e o banco de dados.

## [3.0] - 2026-11-17

### Adicionado
- Implementação do sistema de login funcional com PHP e MySQL.
- Cadastro de usuários com validação dos campos e criptografia de senha usando `password_hash()`.
- Verificação de senha durante o login utilizando `password_verify()`.
- Controle de sessões para identificar usuários autenticados.
- Separação de acesso entre clientes e administradores.
- Redirecionamento conforme o tipo de usuário.
- Menu de perfil com opções específicas para cada tipo de conta.
- Criação e organização do banco de dados MovieFlix.
- Estrutura de tabelas para usuários, filmes, cupons, aluguéis, avaliações e contato.
- Criação das páginas Início, Sobre, Login, Cadastro, Contato e Dashboard.
- Catálogo com categorias, pôsteres, informações e preços dos filmes.
- Ícones para identificação das categorias.
- Criação do `README.md`.
- Criação da pasta `docs/` com documentação do projeto.
- Documentação de instalação, manual do usuário e telas e fluxos.

### Alterado
- Atualização do cabeçalho e rodapé das páginas.
- Reformulação do menu de navegação e do menu de perfil.
- Melhorias na apresentação do catálogo e da página inicial.
- Atualização da identidade visual do MovieFlix 3.0.
- Organização dos arquivos PHP, CSS, JavaScript e imagens.

### Corrigido
- Ajustes na validação e autenticação do login.
- Correções na navegação entre as páginas.
- Ajustes no funcionamento dos formulários.
- Correções visuais no cabeçalho, rodapé e menus.
